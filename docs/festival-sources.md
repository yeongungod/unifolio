## 기존 공개 수상 5편

`site.ts`의 기존 문구를 그대로 연결한다. 날치(정도영), 살아지다(정도영), 침묵(배준원), PD님이 책임지세요(김선연), 목화토금수(박소원). 작품 ID로 연결하므로 표시명을 바꿔도 유지된다. 아미로그·아론 광고 공모전은 작품 대응이 불확실해 특정 행에 연결하지 않았다.

이번 웹 검색에서 목화토금수의 2021년 충무로영화제 올해의 각본상은 [서울예술대학교 영화전공 연혁](https://www.seoularts.ac.kr/web/content.do?proFn=9323150)에서도 확인했다. 기존 5건 모두를 웹에서 독립 검증했다는 뜻은 아니다.

## 보류·범위

- 침묵의 [서울국제프라이드영화제 작품 페이지](https://sipff.kr/1427)는 제목·감독·상영시간은 일치하나 현재 공통 헤더 연도와 과거 상영 일정이 섞여 있어 연도 확정 전 보류했다.
- 배우 프로필에 적힌 PD님이 책임지세요의 해외 영화제 내역은 제작 연도 표기가 기존 기록과 다르고 공식 영화제 프로그램을 확인하지 못해 추가하지 않았다.
- 살아지다의 웹 개봉 연도(2025)와 사이트 작업 연도(2023)는 의미가 달라 작업 연도를 수정하지 않았다.
- 기존 수상 5편 중심으로 검색했다. 전체 영화 38편의 영화제 이력을 전수 조사한 결과는 아니며, 빈칸은 수상·상영 이력이 없다는 뜻이 아니다.

노션 `수상·상영` 텍스트에 해당 작품의 전체 표시 내역을 입력하면 다음 로컬 미리보기에서 그 값이 우선한다. 노션 본문·내부 메모는 자동 수집하지 않는다. 이번에는 노션 원격 수정, 새 데이터 apply, commit, push를 하지 않았다.
