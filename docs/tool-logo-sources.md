Adobe 3종은 현재 공식 제품 페이지에 연결된 아이콘이다. Pro Tools는 공식 릴리스 노트의 컬러 이미지를 사용한다. Cubase는 기존 Steinberg 회사 마크를 제품 마크로 교체했다. Splice 이미지 파일명에는 Cubase13이 남아 있지만 확인일의 Cubase Pro 15 페이지에서 사용 중인 이미지이며, 새 버전 전용 아이콘이라는 뜻은 아니다.

Devicon·Simple Icons에서 가져온 기존 5개 이미지는 더 이상 사용하지 않는다. 각 상표의 권리는 해당 소유자에게 있다. 이미지 비율과 원래 색을 유지하며, Waves는 [사용 지침](https://www.waves.com/downloads/graphic-library/waves-logo)에 따라 공식 제품 페이지로 연결한다.
