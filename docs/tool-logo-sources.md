# 사용 툴 로고 출처

2026-09-22. `public/images/tools/`에 보관하며 브라우저에서 외부 로고 서버를 호출하지 않는다. 로고와 툴 이름은 해당 제품의 공식 사이트로 연결한다.

| photoshop.svg | [Devicon Photoshop](https://github.com/devicons/devicon/blob/master/icons/photoshop/photoshop-original.svg) |
| pro-tools.svg | [Simple Icons 11.15.0 Pro Tools](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/protools.svg) |
| cubase.svg | [Simple Icons 11.15.0 Steinberg](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/steinberg.svg), Cubase 제작사 마크 |
| ableton-live.png | [Ableton 공식 사이트 아이콘](https://cdn-resources.ableton.com/80bA26cPQ1hEJDFjpUKntxfqdmG3ZykO/static/images/apple-touch-icon.fb3597184cb0.png) |
