## 남은 범위와 배포

- ORCA 내장 브라우저의 프레임 끊김은 별도 실기 확인이 필요. 위 브라우저 검증은 Playwright 환경 결과다.
- 클라이언트 로고의 밝은 글자 처리는 일부 로컬 시안이며 공식 다크 CI 일괄 적용이 아님. 출처·원본 보존 기록은 `client-logo-sources.md` 참조.
- 관리자 실로그인·실게시를 이번 검수에서 실행하지 않음. 비공개 초안은 동기화하지 않음.
- commit/push는 사용자 요청 후. 그 직전에 `npm run preflight:publish`로 재확인하고 필요 시 변경을 보존하며 병합한다. 현재 훅은 충돌 가능성이 있으면 중단하며 덮어쓰지 않는다.
