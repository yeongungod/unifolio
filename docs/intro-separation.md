# 소개서 분리 (2026-09-25)

사용자 결정으로 소개서는 별도 문서 프로젝트에서 관리한다. 웹사이트에서는 Contact 소개서 링크, `/intro` 페이지, 사이트맵 항목, PDF 생성 명령과 소개서 전용 스타일을 제거한다.

기존 소개서 원본은 Git 커밋 `dc1cd699dc513332aeaffc1e7a408802d3775652`에 보존된다. 로컬 자산 보관소에도 PDF·Astro 원본·생성 스크립트를 별도 보관했다. 기존 다쪽 회사소개서 프로젝트는 변경하지 않는다.

`npm run pdf`는 폐기됐다. 과거 설계·검수 문서의 `/intro` 및 PDF 생성 안내는 당시 기록이며 현재 운영 지침이 아니다.

현재 배포 페이지: `/`, `/work`, `/admin`. 검증은 `npm run build`, `npm run check`. 이번 제거 변경은 아직 로컬이며 배포 후에는 `/intro`가 404를 반환한다.
